# Contributing

Keep each skill focused, instruction-only, and independently installable.
Edit canonical files in references/ and templates/, then run python3 scripts/sync_resources.py.
Never edit generated resources inside skills/ directly.
Run python3 scripts/sync_resources.py --check before committing.
Preserve the 39-rule inventory, evidence provenance, and discovery versus commitment distinction.
Keep examples synthetic and labeled; do not add private interview data or the source book.
